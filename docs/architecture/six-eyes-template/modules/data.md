# Module: data

Git-tracked markdown state:

- `backlog/` — scored items (ONB/CHK/BIL/LIF/PLT prefixes)
- `pulse-checks/`, `deep-dives/`, `meetings/`
- `bq-knowledge.md` — warehouse gotchas (human authored)
- `state/` — workflow timestamps and run archive
- `staging/` — orchestrated run proposals (`staged/` mirror + `run-manifest.md`); ephemeral files gitignored, demo seed committed

SEED populates fictional Acme content in Stage 2.
